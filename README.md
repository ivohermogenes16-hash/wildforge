# Prancheta — Manager de Futebol

Jogo de treinador de futebol para Android (tela deitada).

**Baixar o APK:** https://github.com/ivohermogenes16-hash/wildforge/releases/download/prancheta-apk/prancheta.apk

- `app/` — o jogo (HTML, CSS e JS)
- `android/` — o aplicativo que roda o jogo em tela cheia
- O GitHub monta um APK novo sozinho a cada atualização deste ramo (`prancheta`).
